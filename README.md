# 📊 Dashboard Ejecutivo de Ventas y Rendimiento

## 🎯 Objetivo

Desarrollar un dashboard ejecutivo en Microsoft Excel para analizar el comportamiento de las ventas, las unidades comercializadas y el ticket promedio, facilitando la identificación de tendencias y diferencias entre productos.

## 🛠️ Herramientas utilizadas

- Microsoft Excel
- Tablas dinámicas
- Gráficos dinámicos
- Segmentadores de datos
- Análisis exploratorio de datos

## 🔎 Principales conclusiones

### 1. Evolución de las ventas

La facturación presenta fluctuaciones a lo largo del período analizado, con un mínimo aparente en febrero y un máximo en octubre. Luego de una caída en septiembre, se observa una recuperación durante octubre.

### 2. Desempeño por producto

PERF-02 presenta la mayor facturación acumulada entre los productos analizados, alcanzando aproximadamente $75,3 millones.

### 3. Relación entre precio y unidades vendidas

El gráfico de dispersión no muestra una relación evidente entre el precio y las unidades vendidas. Por lo tanto, con las variables disponibles no es posible afirmar que un mayor precio implique necesariamente un mayor o menor volumen de ventas.

## 🧐 Análisis crítico: abogado del diablo

Las conclusiones anteriores deben interpretarse considerando algunas variables que no fueron incorporadas al análisis.

- Las variaciones mensuales podrían estar influenciadas por factores estacionales, promociones, días hábiles o cambios en la demanda.
- Una mayor facturación no implica necesariamente una mayor rentabilidad, ya que no se dispone de información sobre costos, descuentos o margen de contribución.
- El volumen vendido puede estar condicionado por disponibilidad de stock, características de los clientes y condiciones comerciales.
- La relación entre precio y unidades podría estar afectada por la agregación de los datos y por diferencias entre productos y clientes.

## ⚠️ Limitaciones

El análisis se realizó sobre las variables disponibles en la base de datos. Para profundizar las conclusiones sería conveniente incorporar información histórica de otros períodos, costos, descuentos, stock, clientes y márgenes de contribución.

Los resultados permiten describir el comportamiento observado, pero no necesariamente determinar las causas de las variaciones.
